# ⚡ ZEUS 1-Click Cloudflare Auto-Deployer (Cloudflare Worker & Pages Edition)

سامانه استقرار خودکار، جهش چندریختی و شخصی‌سازی پنل زئوس روی شبکه جهانی کلودفلر — **کاملاً سرورلس، بدون نیاز به هیچ سکرتی در مخزن و بدون خطای CORS**.

---

## 🚀 روش‌های استقرار و استفاده

### روش اول: استقرار وب‌اپلیکیشن روی Cloudflare Pages (پیشنهادی و قطعی)
به دلیل اینکه فرایند استقرار باید مستقیماً با API کلودفلر ارتباط برقرار کند، اجرای وب‌اپلیکیشن روی شبکه خودِ کلودفلر مانع از خطای CORS و چالش‌های امنیتی مرورگر می‌شود:
1. این مخزن را در حساب گیت‌هاب خود **Fork** یا **Push** کنید.
2. در داشبورد Cloudflare به بخش **Workers & Pages -> Create application -> Pages -> Connect to Git** بروید.
3. مخزن گیت‌هاب را انتخاب کنید (نیازی به تنظیم Build command نیست؛ کلودفلر خودکار فایل `_worker.js` را به عنوان فول‌استک ورکر تشخیص می‌دهد).
4. پس از ۱ دقیقه، آدرس اختصاصی بدون فیلتر `https://[نام-پروژه].pages.dev` به شما داده می‌شود.
5. وارد آدرس شوید، توکن کلودفلر خود را وارد کرده و دکمه **استقرار** را بزنید!

---

### روش دوم: کپی مستقیم در یک Cloudflare Worker
1. در داشبورد کلودفلر به بخش **Workers & Pages -> Create Application -> Create Worker** بروید.
2. کد موجود در فایل `_worker.js` را در بخش ادیتور ورکر Paste کرده و دکمه **Deploy** را بزنید.
3. آدرس دامنه ورکر را در مرورگر باز کنید و توکن را برای ساخت خودکار پنل زئوس وارد نمایید.

---

### روش سوم: اجرای مستقیم از تب GitHub Actions (بدون سکرت)
1. در صفحه مخزن در گیت‌هاب به سربرگ **Actions** بروید.
2. از منوی سمت چپ گزینه **Deploy Zeus Worker to Cloudflare** را انتخاب کنید.
3. روی دکمه آبی **Run workflow** کلیک کرده و توکن کلودفلر خود را موقتاً وارد نمایید.
4. سرورهای اوبونتو گیت‌هاب سورس را مبهم‌سازی کرده، دیتابیس D1 را می‌سازند و لینک نهایی پنل را در گزارش خروجی نمایش می‌دهند.

---

## 🔑 دسترسی‌های مورد نیاز برای توکن کلودفلر
- `Account` -> `Workers Scripts` -> `Edit`
- `Account` -> `D1` -> `Edit`
- `User` -> `Memberships` -> `Read`

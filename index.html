🚀 استقرار ۱۰۰٪ خودکار بدون نیاز به هیچ سکرتی در مخزن

کافی است Cloudflare API Token خود را وارد کنید. سیستم مستقیماً در مرورگر شما مشخصات اختصاصی (نام پوششی تصادفی، مسیر ادمین، UUID نسخه ۴) را تولید کرده، سورس Z-E-U-S را مبهم‌سازی نموده و آن را روی حساب کلودفلر شما منتشر می‌کند.

دسترسی‌های مورد نیاز توکن در کلودفلر: Account:Workers Scripts (Edit) و Account:D1 (Edit) و User:Memberships (Read)

⚠️ محدودیت شبکه یا فایروال مرورگر (CORS)

مرورگر شما به دلیل قوانین امنیتی CORS یا فیلترینگ نتوانست مستقیماً به سرور api.cloudflare.com متصل شود. نگران نباشید! مخزن شما مجهز به رانر خودکار GitHub Actions است که بدون هیچ محدودیتی از روی سرورهای گیت‌هاب اجرا می‌شود:

روش اجرای بدون فیلتر در ۳ کلیک:
۱. در صفحه همین مخزن در گیت‌هاب به سربرگ Actions بروید.
۲. از منوی سمت چپ گزینه Deploy Zeus Worker to Cloudflare را انتخاب کنید.
۳. دکمه آبی Run workflow را بزنید، توکن را Paste کنید و تایید کنید تا در ۳۰ ثانیه دیپلوی شود!
